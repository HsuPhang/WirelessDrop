# WirelessDrop 项目介绍
## 一、项目概述
WirelessDrop 是一款基于 Python 开发的轻量级无线文件传输 Web 应用，旨在简化不同设备间的文件共享流程。用户可通过浏览器访问应用，完成文件上传、传输等操作，无需依赖复杂的第三方工具，具备轻量、易用、跨设备的特性。

## 二、项目结构
```
WirelessDrop/
├── .gitignore               # Git 忽略规则配置文件
├── App.py                   # 项目入口文件（启动应用）
├── templates/               # 前端HTML模板目录
│   ├── index.html           # 应用首页模板
│   └── upload.html          # 文件上传页面模板
└── app/                     # 项目核心业务逻辑目录
    ├── __init__.py          # 应用初始化文件（Flask应用实例定义等）
    ├── config.py            # 项目配置文件（数据库、路径、密钥等配置）
    ├── routes/              # 路由处理目录（接口/页面路由定义）
    ├── static/              # 静态资源目录（CSS、JS、图片等）
    └── utils/               # 工具函数目录（文件处理、格式转换等）
```

### 核心文件/目录说明
- **App.py**：项目启动入口，负责初始化 Web 应用并启动服务；
- **templates/**：存放前端页面模板，遵循 Web 框架（如 Flask）的模板渲染规范；
- **app/routes/**：定义应用的 URL 路由，关联前端页面与后端处理逻辑；
- **app/config.py**：集中管理项目配置，便于环境切换（开发/生产）和参数调整；
- **app/utils/**：封装通用工具函数，降低代码冗余（如文件校验、大小限制、格式转换等）。

## 三、Git 忽略规则说明
`.gitignore` 文件定义了项目中无需纳入版本控制的文件/目录，核心忽略项及设计思路如下：

| 忽略类型                | 具体项                  | 说明                                                                 |
|-------------------------|-------------------------|----------------------------------------------------------------------|
| Python 编译/缓存文件    | `__pycache__/`、`*.pyc` | 避免提交 Python 运行时生成的编译文件，减少仓库体积                   |
| 虚拟环境                | `venv/`、`env/`         | 虚拟环境为本地开发依赖，无需同步，开发者可自行搭建                   |
| 业务相关目录            | `uploads/`              | 存放用户上传的文件，属于动态内容，不纳入版本控制                     |
| 日志/测试相关           | `*.log`、`.coverage`    | 日志文件、测试覆盖率报告为本地生成，无需同步                         |
| 编辑器/系统配置         | `.vscode/`、`.DS_Store` | 忽略不同编辑器/操作系统生成的个性化配置文件，保证仓库纯净             |
| 敏感/配置文件           | `.env`、`.env.local`    | 忽略包含密钥、数据库密码等敏感信息的环境配置文件，避免信息泄露       |
| 数据库文件              | `*.db`、`*.sqlite3`     | 数据库文件为本地运行产物，按需备份，不纳入版本控制                   |
| 构建/打包文件           | `build/`、`dist/`       | 项目打包、构建生成的文件，仅在发布时需要，无需日常提交               |

## 四、技术栈
- 后端：Python（核心框架大概率为 Flask，适配 routes/templates/static 目录结构）；
- 前端：HTML（模板渲染）、可选 CSS/JavaScript 增强交互；
- 开发规范：遵循 Python 项目最佳实践，通过虚拟环境管理依赖，分离配置与业务逻辑。

## 五、快速上手指引
1. 克隆项目到本地；
2. 搭建 Python 虚拟环境（`venv`/`env`）并激活；
3. 安装项目依赖（需补充 `requirements.txt` 或根据代码推导依赖）；
4. 运行 `App.py` 启动 Web 服务；
5. 浏览器访问指定地址（如 `127.0.0.1:5000`），即可使用文件传输功能。
